# Dari Kelas, Jadi Karya

Microsite interaktif mobile-first untuk berbagi insight dari kisah Bu Guru Ria kepada tiga komunitas:

- Alumni Guru Penggerak
- Guru Informatika
- Guru IPA

## Fitur

- Tiga jalur konten berbeda dalam satu tautan
- Delapan node problem-solving yang dapat diklik
- Progress eksplorasi
- Refleksi tahap perkembangan karya
- Pembuat kartu refleksi
- Unduh kartu sebagai PNG
- Web Share API / salin tautan
- Tanpa database dan tanpa dependensi eksternal

## Unggah ke GitHub Pages

1. Buat repository baru, misalnya `dari-kelas-jadi-karya`.
2. Upload file `index.html` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch **main** dan folder **/(root)**, lalu klik **Save**.
6. Tunggu sampai alamat GitHub Pages muncul.

Contoh alamat:

`https://USERNAME.github.io/dari-kelas-jadi-karya/`

## Kustomisasi cepat

Semua isi, warna, dan jalur berada di satu file `index.html`.
Cari objek JavaScript bernama `journeys` untuk mengubah konten tiap kelompok.
